# Цена герба

Визуальная новелла о поместье герцогини Элеоноры Вальден. Мира, переписчица из низшего сословия, замечает, что льгота деревням и книга сборов не сходятся. Войны и романа в истории нет: спор идёт о подписи, налоге и о том, чьему слову верят.

Сделано на **C#** и **Unity**. Сейчас можно пройти **главу I «Чужая подпись»**. Главы II–V стоят в оглавлении и будут дописаны следом. Одна глава рассчитана примерно на пятнадцать минут чтения.

## Как открыть

1. Установите редактор **Unity 2022.3 LTS** через Unity Hub.
2. В Hub выберите **Add** → **Add project from disk** и укажите эту папку.
3. Дождитесь импорта. Откройте сцену `Assets/Scenes/Main.unity`.
4. Нажмите **Play**.

Игра собирает экран сама при запуске любой сцены. Окно лучше держать в пропорции 16:9.

## Как играть

- Щелчок или пробел — следующая реплика. Если строка ещё печатается, первое нажатие дописывает её сразу.
- Внизу появляются выборы. Они меняют четыре шкалы: внимательность, доверие Агаты, долг деревни, подозрение Себастьяна.
- В конце главы видно, остался ли у Миры лоскут с двумя подписями.

## Где текст

Сюжет первой главы лежит в `Assets/Scripts/Story/ChapterOne.cs` и не зависит от Unity. Движок экрана — `Assets/Scripts/VN/VNController.cs`. Новую главу можно добавить рядом с первой и отметить её доступной в `StoryCatalog.cs`.

Проверка всех 54 путей главы без редактора:

```bash
dotnet run --project tools/StoryCheck/StoryCheck.csproj
```

Нужен .NET SDK 8.

## Как собрать приложение для Windows

1. Открой проект в Unity 2022.3 LTS.
2. Меню **File → Build Settings**.
3. Платформа **Windows**. Если она не активна, нажми **Switch Platform** и дождись окончания.
4. В списке сцен должна быть `Assets/Scenes/Main.unity`. Если её нет, открой сцену и нажми **Add Open Scenes**.
5. **Player Settings**: Fullscreen Mode поставь **Windowed**, размер **1920×1080**, имя продукта — «Цена герба».
6. **Build**. Укажи пустую папку, например `C:\Games\CenaGerba`.

В папке появится `CenaGerba.exe` и папка `CenaGerba_Data`. Это и есть приложение: их нужно держать рядом. Запуск — двойной щелчок по exe. Чтобы передать игру, заархивируй exe, папку `_Data` и остальные файлы, которые Unity положила рядом.
